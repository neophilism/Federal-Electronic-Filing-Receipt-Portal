# UFR-015 public website shell

## Contract and boundary

Public presentation contract version 1 serves `/`, `/agencies`, `/help`, `/privacy` and `/about`, plus the exact allowlisted `/assets/public-shell.v1.css` resource. GET and HEAD are supported for those resources; mutation methods receive 405 with an accurate Allow header. Existing JSON health, readiness and policy contracts remain distinct.

Every page identifies the development prototype, disclaims government filing authority and states that submissions are not accepted. There are no forms, accounts, uploads, tracking lookups, cookies, browser storage, analytics, external fonts or client scripts. Navigation is ordinary HTML and works without JavaScript. Semantic landmarks, a keyboard skip link, active-page state, visible focus indicators and responsive layouts are included; full accessibility acceptance remains a later unit.

The human-readable agency directory consumes only the already validated immutable UFR-005 registry. Missing, empty, expired, rollback or unavailable configuration produces an empty information state without inventing entries or exposing dependency diagnostics. Reviewed records are escaped as text and link only to validated exact HTTPS hosts and the provenance source. It neither sends filings nor creates a receipt. This is Federal presentation, not a fork of upstream processing.

## Security review and verification

`npm run check` passes canonical 60-unit registry validation, module syntax checks and 26 Node tests. Six added integration tests exercise every page/link/stylesheet, safe HEAD, refused mutation methods, content-security/privacy headers, strict hostile request targets, missing/expired/rollback directory states, thrown dependency errors and injected markup in registry names. Tests use loopback and synthetic records; they do not contact institutions or read protected records.

Source review checked the explicit route allowlist (no filesystem path derived from a request), contextual HTML escaping, prohibition of forms/scripts by CSP, failure-state redaction, no third-party assets and unchanged fail-closed readiness. Browser rendering was attempted in the available Playwright package, but launch returned `Executable doesn't exist` for its configured Chromium headless shell. No browser, visual or WCAG conformance pass is claimed. Hosted CI must be observed for the exact committed SHA before merge.

## Run and rollback

Use Node 22 or newer: `npm run check`, then `npm start`; open the loopback URL on the configured port (default 3000). No account, credential, dependency install or paid service is required. The directory is intentionally unavailable unless the reviewed registry is explicitly pinned as described in AGENCY_POLICY.md.

Rollback means deploy the previous reviewed source revision. This unit persists no claimant records, receipts or sessions. No live deployment or institutional acceptance is claimed.
