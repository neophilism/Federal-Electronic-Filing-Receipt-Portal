## Implemented behavior

The read-only Federal policy contract explicitly disables filing acceptance, government receipt claims, classified collection and authoritative deadline computation. The agency registry requires exact UTF-8 configuration bytes, trusted SHA-256 and minimum revision, bounded source/review dates, exact reviewed hosts and provenance links. It rejects malformed, ambiguous, conflicting and stale data. Its immutable issued snapshot prevents an arbitrary object from supplying a false authority response to the HTTP server.

The actual process aborts before listening on missing/tampered configuration. No configuration yields an unavailable directory. Runtime expiry or dependency failure returns 503 without entries or raw diagnostics. Neither the registry nor an agency homepage sends a filing, computes a legal deadline, creates a receipt or replaces Secure Intake logic.

The optional single-host DOJ sample is a dated primary-source review, not complete component coverage. Portal-local agency IDs and a local 31-day review limit are engineering choices, not an upstream schema or a statutory rule. Full source and deployment-pin boundaries are in docs/AGENCY_POLICY.md.

## Verification

Local `npm run check` passed: 60-unit registry DAG validation, syntax checks for all application modules, and 20 tests. Negative cases include domain suffix/subdomain spoofing, obfuscated URLs, stale/future provenance, revision and clock rollback, duplicate keys/ownership, malformed/oversized files, mutation attempts, unavailable dependencies, actual subprocess startup denial and loopback HTTP methods/statuses.

Hosted CI must be observed on the committed head before claiming a hosted pass or merging. No live deployment, institution authorization, legal sufficiency, complete agency census or credentialed intake acceptance is claimed.

## Rollback

Restore the preceding reviewed source/configuration as a deployment action with a separately reviewed digest/revision floor. Do not re-enable expired entries or lower the pin solely to obtain a healthy result. This unit writes no claimant data or durable receipt and requires no new service or spending.
